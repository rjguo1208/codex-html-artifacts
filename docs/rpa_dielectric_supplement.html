Scope

The supplemental workflow computes the free-carrier electronic screening caused by doping. It does not include the phonon poles in this dielectric function. The phonons enter later through the long-range polar electron-phonon vertex and the plasmon-phonon hybrid-mode problem.

The response is evaluated in the random phase approximation. Local-field effects are neglected, so the object used for the long-wavelength hybridization model is a scalar macroscopic response at the chosen q direction rather than a full G,G' dielectric matrix.

Carrier Occupation

The band structure and wavefunctions are taken from the undoped crystal. A carrier density fixes the chemical potential, and the doped-carrier occupation change is denoted by delta f.

nV = 2 Nk ∑nk δfnk

Here n is the carrier density, V is the primitive-cell volume, and the factor of 2 is spin degeneracy. For n-doped GaAs this is the conduction-band free-carrier occupation near the CBM.

Bare RPA Response

The bare doped-carrier susceptibility is the doped-carrier Lindhard response evaluated with interpolated band energies and cell-periodic wavefunction overlaps.

δχ 0 (q,ω) = 2 Nk ∑ nmk ( δfm,k+q - δfn,k ) | ⟨ um,k+q | un,k ⟩ | 2 εm,k+q - εn,k + ω + iη

The supplement evaluates the overlap with Wannier-interpolated eigenvectors. This matters for a direct reproduction: a parabolic-band overlap of one is useful for tests, but it is not the paper-level RPA input.

Wavefunction Overlap Treatment

The overlap factor is the density-operator matrix element between the cell-periodic parts of two Bloch states. It is not an electron-phonon vertex and should not be replaced by the short-range EPW electron-phonon matrix element.

In the supplement, the direct RPA calculation evaluates this term with Wannier interpolation. The practical construction is to build the Wannier-gauge Hamiltonian at both k and k+q, diagonalize both matrices, and take the overlap of the resulting eigenvectors in the same Wannier basis.

HW (k) C (k) = C (k) E (k)
Smn (k,q) = [ C† (k+q) C (k) ] mn = ∑a Cam* (k+q) Can (k)
| ⟨ um,k+q | un,k ⟩ | 2 ≈ | Smn (k,q) | 2

This approximation assumes the Wannier basis is a common localized basis for nearby k points, so the basis overlap is effectively the identity. It is the small-q approximation explicitly used in the supplement, and it is appropriate for the Fig. 1 wave vector |q| = 8e-4 Angstrom^-1.

evals_k, vecs_k = eigh(H_wannier(k))
evals_kq, vecs_kq = eigh(H_wannier(k + q))

S = vecs_kq.conj().T @ vecs_k
overlap2 = abs(S[m, n])**2

Band-Diagonal Identity Approximation

A lower-cost approximation is to replace the wavefunction overlap factor by a band-diagonal Kronecker delta. This is the precise meaning of the identity overlap backend.

| ⟨ um,k+q | un,k ⟩ | 2 ≈ δmn

For a single isolated conduction band, this further reduces to an intraband matrix element equal to one:

| ⟨ uc,k+q | uc,k ⟩ | 2 ≈ 1 
if overlap_mode == "identity":
    overlap2 = 1.0 if m == n else 0.0

This can be an acceptable controlled approximation for GaAs Fig. 1-style screening when the response is dominated by intraband transitions in the lowest conduction band, q is very small, and the band character changes weakly between k and k+q. It should still be recorded explicitly as overlap_mode=identity_delta and, if possible, benchmarked against the Wannier-eigenvector overlap for representative densities.

Interacting RPA Response

The interacting response follows from scalar RPA screening by the long-range Coulomb interaction.

δχ (q,ω) = δχ0 (q,ω) 1 - Uq δχ0 (q,ω)
εel-1 (q,ω) = 1 + Uq δχ (q,ω) = [ 1 - Uq δχ0 (q,ω) ] -1

Coulomb Kernel

The Coulomb interaction is screened by the undoped high-frequency dielectric tensor along the selected q direction.

Uq = 4πe2 q2 εq^ V
εq^ = q^ · ε∞ · q^

This convention is important for avoiding double counting: epsilon_inf handles the undoped electronic background, while delta chi adds only the doped free-carrier response.

Plasmon-Pole Fit

The frequency-dependent RPA inverse dielectric function is compressed into a plasmon-pole model before the phonon hybridization step.

Static Approximation Used for the Blue Curve

The supplement's static comparison replaces the dynamic plasmon pole by a high-energy fixed pole that reproduces the static inverse dielectric function.

ωq0 = ω* = 5 eV , γq0 = 0
Ωq0 = ω* 1 - εel-1 (q,0)

This is the construction that makes the static screened LO-like branch collapse toward the TO phonon at high density in the paper discussion.

Implementation Status

The local fig1_rpa_response.py module implements the supplement-form RPA response core for supplied band grids and writes compact public-safe CSV tables. It includes carrier-density to chemical-potential solving, spin degeneracy, normalized k weights, primitive-cell volume conversion, identity_delta overlap, direct delta chi0(q,omega), the screened Coulomb kernel U_q, and epsilon_el^{-1} = [1 - U_q delta chi0]^{-1}.

The second implementation step connected the RPA core to the local GaAs Wannier Hamiltonian. The module now reads Wannier90 *_hr.dat files, evaluates H^W(k) using exp(2*pi*i*k.R)/deg(R), diagonalizes H(k) and H(k+q), and constructs |C(k+q)^dagger C(k)|^2. The local GaAs gaas_zb_prim_hr.dat parses as 8 Wannier functions and 617 R points; sampled H(k) Hermiticity error is below 1e-10.

The third implementation step generated a local GaAs Wannier-RPA smoke table for the Fig. 1 q point. The smoke uses a 9x9x9 Gamma-centered k mesh, Gamma conduction band index 4, T=300 K, eta=3 meV, and densities 1e17, 5e17, and 1e18 cm^-3. The mean Wannier overlap squared is 0.9999358 and the minimum is 0.9994422; max |Delta epsilon_el^{-1}| between identity_delta and wannier_eigenvector is 7.71e-4, 2.38e-3, and 1.01e-2 for the three densities.

The full regression suite now has 62 passing unittest cases in the requested Anaconda/Tmat environment. The next implementation step is to validate conduction-band tracking before scaling the workflow toward the supplement's dense 200x200x200 GaAs k grid.
