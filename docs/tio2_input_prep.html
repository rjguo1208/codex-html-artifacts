Run Order

The production route now uses the 6-atom primitive-cell templates. The intended local command order is:

module reset
module load aocc/3.1.0 openmpi/4.1.6
module load amdblis/3.0 amdlibflame/3.0 amdlibm/3.0 fftw

QE=/anvil/projects/x-che190065/rjguo/qe-7.5/bin

$QE/pw.x -in dft/tio2/primitive/relax/tio2_anatase_primitive_relax.in > dft/tio2/primitive/relax/tio2_anatase_primitive_relax.out

# Copy final relaxed ATOMIC_POSITIONS into the SCF input first.
$QE/pw.x -in dft/tio2/primitive/scf/tio2_anatase_primitive_scf.in > dft/tio2/primitive/scf/tio2_anatase_primitive_scf.out

$QE/ph.x -in dft/tio2/primitive/ph/tio2_anatase_primitive_ph_gamma_eps.in > dft/tio2/primitive/ph/tio2_anatase_primitive_ph_gamma_eps.out
$QE/ph.x -in dft/tio2/primitive/ph/tio2_anatase_primitive_ph_grid_4x4x4.in > dft/tio2/primitive/ph/tio2_anatase_primitive_ph_grid_4x4x4.out
