Interpretation

The avoided-crossing figure is the cleanest visualization of plasmon-phonon hybridization. Without coupling, the bare plasmon line and phonon level would cross. With nonzero coupling, the eigenvalues of the plasmon-phonon dynamical matrix repel, producing two hybrid modes. This is the toy analog of the resonant regime discussed in the paper and later targeted in GaAs and TiO2.

The spectral-function figure checks that the Green-function observable is consistent with those hybrid modes. The static-PPM figure verifies the separate static approximation used as a control calculation in the reproduction plan.

The toy model was run with the requested HPC environment:

python toy_model_plph.py

The plotting command writes the public PNG files to figures/toy_model/. For this GitHub Pages report, the three small PNG files were copied to docs/assets/ and referenced with relative paths.

Matplotlib emitted a cache-directory warning when MPLCONFIGDIR=/tmp/matplotlib-cache was not writable; it automatically used a temporary cache. This did not affect the generated figures.
