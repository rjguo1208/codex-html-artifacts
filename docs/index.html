Short Summary

The direct GaAs Fig. 1 first-pass pipeline is now implemented end to end. It starts from the local GaAs Wannier Hamiltonian, evaluates a Gamma-centered conduction-pocket RPA response at the paper q point, fits plasmon-pole parameters, builds the long-range LO-plasmon two-mode hybrid branches, writes the static and bare-plasmon curves, adds explicitly marked approximate digitized Ref. [8] points, and renders docs/assets/gaas_fig1_direct.svg.

Current production settings: 41x41x41 Gamma cube, half-width 0.035 crystal units, absolute BZ weight sum 3.43e-4, 81 density points uniform in sqrt(n)/10^9, 181 frequencies from 0 to 180 meV, T=300 K, |q|=8e-4 Angstrom^-1, and eta=3 meV. PPM status is 81/81 ok; the 0.3 eV tracking window has 20285 k points and minimum transition overlap 0.9994421923.

The current public Fig. 1 SVG now uses the same Wannier-RPA plasmon-pole table but replaces the problematic benchmark dielectric/Born input by the reference GaAs material input epsilon_inf=10.89, |Z*|=2.18. The reference polar strength is sqrt(S_polar)=14.22302904168 meV, giving an effective LO diagonal energy 35.26193680836 meV from sqrt(TO^2+S_polar).

The generated reference-material result has bare-plasmon energy 4.665-84.336 meV, nonadiabatic hybrid branch energies 4.263-85.722 meV, and a static approximation branch 32.277-35.181 meV. This is now a direct Wannier-RPA artifact, not a toy, Drude, parabolic, or numerical-Lindhard surrogate.

The requested four-step validation pass is also complete. k-mesh, frequency-grid, and eta changes are sub-meV at the representative densities; 0.035 remains the retained Gamma-pocket half-width; 0.040 is rejected by band-window diagnostics; final PPM status is 81/81 ok with maximum relative residual 1.50e-1 at the highest-density edge.

The latest diagnostic checks the local Wannier conduction-band curvature directly. A symmetric Gamma fit gives average m*=0.0159 m_e at kmax=0.005 Angstrom^-1; near the highest-density Fermi wavevector kF=0.0449 Angstrom^-1, the kmax=0.040 Angstrom^-1 fit gives average m*=0.0266 m_e. Relative to reference GaAs m*=0.067 m_e, this can raise the plasmon energy scale by about 1.59x, so the high-density upper-branch mismatch is now traced primarily to the electronic-structure/RPA input rather than the plot annotation.

A follow-up mass-scaled diagnostic now rescales the fitted PPM pole by s(n)=sqrt(m*_W(kF)/0.067) and rebuilds the same polar two-mode hybrid. This reduces the interpolated guide RMSE from 9.287120 meV to 4.573280 meV, confirming that effective mass is a dominant error source. However, the highest-density upper branch changes from +14.929752 meV above the guide to -12.851112 meV below it, so this scaling is an overcorrection diagnostic, not a replacement for a material-faithful RPA calculation.

The Fig. 1 hybrid step now uses a stricter long-range polar coupling path. It parses QE Born effective charges, the high-frequency dielectric tensor, masses, cell volume, the exact-Gamma LO eigenvector, and the Cartesian Fig. 1 q direction, then computes the polar oscillator strength from the SI nonanalytic dynamical matrix. The local nonadiabatic CSV now records coupling_source=born_epsilon_eigenvector_si; the absolute strength agrees with the QE LO-TO splitting at ratio 0.9996852769256.

The new multi-direction polar-coupling scan checks [100], [110], and [111]. All three give sqrt(S_polar)=5.071342392659 meV and relative strength 1.000000000000, consistent with cubic GaAs symmetry.

A new dielectric-input sensitivity check shows why the current benchmark epsilon_inf≈107 must be isolated before production claims. Replacing only epsilon_inf by 10.89 while keeping the same Born tensor scales S_polar by 9.835663692011 and increases the nearest-crossing hybrid gap from about 5.07 meV to 16.31 meV.

Interpretation

The avoided-crossing figure is the cleanest visualization of plasmon-phonon hybridization. Without coupling, the bare plasmon line and phonon level would cross. With nonzero coupling, the eigenvalues of the plasmon-phonon dynamical matrix repel, producing two hybrid modes. This is the toy analog of the resonant regime discussed in the paper and later targeted in GaAs and TiO2.

The spectral-function figure checks that the Green-function observable is consistent with those hybrid modes. The static-PPM figure verifies the separate static approximation used as a control calculation in the reproduction plan.
