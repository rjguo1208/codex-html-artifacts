Why GaAs

GaAs is a practical low-cost benchmark for the plasmon-phonon workflow because the zincblende primitive cell has only two atoms and six phonon branches. It is also polar, so Gamma dielectric response, Born effective charges, and LO-TO splitting remain relevant. It is not a material-faithful replacement for TiO2; it is a workflow and debugging surrogate.

Static Approximation Branch

The static branch uses the same numerical Lindhard data but freezes the electronic screening at the low-energy/static inverse dielectric value. In the current toy interface this is equivalent to a high-energy static PPM pole at omega*=5 eV whose coupling reproduces a statically screened LO-like phonon.

ωstatic LO2(q,n) = ωTO2 + εel-1(q,0;n)[ωLO2 - ωTO2]
cstatic = ω* sqrt{[1 - εel-1(q,0;n)][ωLO2 - ωTO2]}
