Core Policy

Internal calculations should use atomic units. Human-facing output should use eV or meV for energies, Angstrom for lengths, and cm-3 for carrier density.

The main invariant is:

Every element of C_tilde must have units of energy squared.

Conversion Constants

Constant Value Use
HA_TO_EV 27.211386245988 Convert Hartree to eV.
RY_TO_EV 13.605693122994 Convert Ry to eV.
BOHR_TO_ANG 0.529177210903 Convert bohr to Angstrom.
ANG_TO_BOHR 1.8897261246257702 Convert Angstrom to bohr.
CM_TO_BOHR 1.8897261246257702e8 Convert cm to bohr.

Cell Volume and Carrier Density

Use the actual simulation cell vectors from the same QE / Wannier / EPW calculation. Do not mix primitive and conventional cell volumes.

a_i[bohr] = a_i[Angstrom] * ANG_TO_BOHR
V_cell = abs(dot(a1, cross(a2, a3)))      # bohr^3

n_bohr = n_cm3 / CM_TO_BOHR^3             # bohr^-3
N_dop_cell = n_bohr * V_cell              # electrons / simulation cell

If spin is not explicitly resolved, the occupation sum should include the spin degeneracy factor 2. If spin channels are explicit, sum over spin channels instead.

RPA and Coulomb Units

The screened macroscopic Coulomb interaction is evaluated in atomic units:

epsilon_inf_qhat = dot(q_hat, epsilon_inf @ q_hat)
U_q = 4*pi / (V_cell * q_norm^2 * epsilon_inf_qhat)   # Ha

The free-carrier susceptibility should have units Ha-1, so U_q * delta_chi0 is dimensionless:

epsilon_el_inv(q, omega) = 1 / (1 - U_q * delta_chi0(q, omega))

Plasmon-Pole and Coupling Checks

epsilon_el_inv(q, omega) - 1
  = Omega_q0^2 / ((omega + i*gamma_q0)^2 - omega_q0^2)

Use Omega_q0, omega_q0, and gamma_q0 in Hartree internally.

g_lr_q0 = Omega_q0 * sqrt(U_q)
c_qnu = g_lr_q0 * g_lr_qnu / U_q
      = Omega_q0 * g_lr_qnu / sqrt(U_q)

The invariant implementation check is c_qnu must have units Ha2. If this fails, do not proceed to real-material calculations.

Dynamical Matrix Requirements

C_tilde =
[[omega_q0^2, c_q1,       c_q2,       ...],
 [c_q1*,      omega_q1^2, 0,          ...],
 [c_q2*,      0,          omega_q2^2, ...],
 ...]
  • Check: diagonal terms are Ha2.
  • Check: off-diagonal coupling terms are Ha2.
  • Check: the zero-linewidth matrix is Hermitian.
  • Check: decoupled modes with c_qnu = 0 keep their bare frequency.

Finite-Linewidth Sign Convention

lambda_qbeta = omega_tilde_qbeta - i * gamma_tilde_qbeta

Physical damping means Im(lambda_qbeta) <= 0 and gamma_tilde_qbeta = -Im(lambda_qbeta) >= 0.

Static Approximation

omega_q0 = omega_star = 5 eV
gamma_q0 = 0
Omega_q0 = omega_star * sqrt(1 - epsilon_el_inv(q, 0))

Convert omega_star to Hartree before internal use. For omega << omega_star, the low-energy inverse dielectric response should approach epsilon_el_inv(q, 0).

Stop Conditions

  • U_q * delta_chi0 is not dimensionless.
  • C_tilde off-diagonal terms are not energy squared.
  • A decoupled mode shifts in a toy or real-material check.
  • The finite-linewidth solver gives positive imaginary eigenvalues for physical damping.
  • The same carrier density maps to different electrons per cell because of primitive/conventional cell confusion.
  • Small-q anisotropic results lose the direction q_hat.
