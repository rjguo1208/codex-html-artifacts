1. Toy Model Parameters

The displayed figures use one plasmon and two phonon modes. Only the first phonon is coupled to the plasmon; the second phonon is intentionally decoupled as a control.

Quantity Value used in the default check Meaning
omega_pl 80 meV for the check; swept for the avoided-crossing figure Bare plasmon energy.
omega_ph,1 100 meV Coupled phonon mode.
omega_ph,2 160 meV Decoupled phonon mode.
c1 0.0018 i eV2 Plasmon-phonon coupling amplitude.
c2 0 Control coupling for the decoupled phonon.

2. Zero-Linewidth Dynamical Matrix

The zero-linewidth toy model diagonalizes the plasmon-phonon dynamical matrix.

C~ = ωpl2 c1 c2 c1* ωph,12 0 c2* 0 ωph,22 
C_tilde =
[[omega_pl^2, c1, c2],
 [c1*, omega_ph,1^2, 0],
 [c2*, 0, omega_ph,2^2]]

3. Hybrid Mode Eigenproblem

The hybrid energies are the square roots of the eigenvalues of the matrix above.

C~ V~β = ω~β2 V~β Eβ = ω~β = λβ ( C~ ) 
C_tilde V_beta = omega_tilde_beta^2 V_beta
E_beta = omega_tilde_beta = sqrt(lambda_beta(C_tilde))

4. Avoided Crossing Formula

Because c2 = 0, the second phonon remains exactly fixed. The avoided crossing is controlled by the two-mode plasmon plus coupled-phonon block.

E± = ωpl2 + ωph,12 ± ωpl2 - ωph,12 2 + 4 c1 2 2 
E_+- = sqrt((omega_pl^2 + omega_ph,1^2
            +- sqrt((omega_pl^2 - omega_ph,1^2)^2 + 4 |c1|^2)) / 2)

The third energy is simply E3 = omega_ph,2 because the decoupled mode has c2 = 0.

6. Finite-Linewidth Solver

The finite-linewidth check follows the damped-oscillator construction used in the supplemental material. A phase transform first makes the coupling block real.

Φ = diag ( 1 , eiφ1 , eiφ2 ) eiφν = cν cν A = 12 Φ C~ Φ† + I - i Γ~ B = 12 Φ C~ Φ† - I A B -B* -A* x y = λ x y 
Phi = diag(1, exp(i phi_1), exp(i phi_2))
exp(i phi_nu) = c_nu / |c_nu|
A = 1/2 (Phi C_tilde Phi^dagger + I) - i Gamma_tilde
B = 1/2 (Phi C_tilde Phi^dagger - I)
[[A, B], [-B*, -A*]] [x, y]^T = lambda [x, y]^T

The positive branch is written as follows, so a physical linewidth has a negative imaginary part.

λβ = ω~β - i γ~β

7. Static Plasmon-Pole Check

The static approximation fixes a high plasmon-pole energy and chooses the pole strength to reproduce a target static inverse dielectric function at low energy.

ω0 = ω* = 5 eV Ω0 = ω* 1 - εel-1 (0) εel-1 (ω) = 1 + Ω02 ω2 - ω*2 ≈ εel-1 (0) 
omega_0 = omega* = 5 eV
Omega_0 = omega* sqrt(1 - eps_el^{-1}(0))
eps_el^{-1}(omega) = 1 + Omega_0^2 / (omega^2 - omega*^2)
eps_el^{-1}(omega << omega*) approximately eps_el^{-1}(0)

8. Toy Inverse Dielectric Loss

The fitted-PPM GaAs loss check uses the plasmon coordinate Green-function element. The external longitudinal field is coupled only to the plasmon coordinate in this toy interface; phonons affect the response through the full hybrid Green function.

εpl-ph-1 (ω) = ε∞-1 + Ω2 G00 (ω) L (ω) = - Im εpl-ph-1 (ω) 
eps_plph_inv(omega) = eps_inf^{-1} + Omega^2 * G_00(omega)
loss(omega) = -Im eps_plph_inv(omega)

In the zero-coupling, zero-linewidth limit, G_00 = 1/(omega^2 - omega_pl^2), so this reduces to the bare plasmon-pole expression.
